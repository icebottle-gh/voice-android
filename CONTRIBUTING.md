# Contributing to VP25 (Voice Project 2025)

Thank you for your interest in contributing. This project follows a task-based contribution model combining volunteer and paid work.

## Contribution Model

Work is organised as **open tasks** published on [Nexus](https://discord.gg/AuVQcxSz) - the discord server used for this project  

Contributors may:  
* Volunteer to complete a task
* Submit a bid for a task
* Indicate an expected payment amount (for bids on bounty tasks)

* Most contributions are expected to be voluntary, but some tasks may be marked as bounty tasks:

### **Bounty Tasks**

Bounty Tasks are tasks with an allocated budget where a contributor may include an expected payment in their bid.  Selection of a contributor is at the maintainer’s discretion.

---

## Sprint Workflow

The work planning for the project follows short **1 week agile sprints**.

In each sprint:
* Independently implementable tasks are published
* Contributors bid or volunteer
* A contributor is delegated the task
* Completed work is reviewed and merged continuously (no batch releases)

Tasks may roll over to the next sprint if unfinished.

## How to Contribute

1. Review open tasks
2. Comment or bid on a task
3. Wait for delegation/approval
4. Complete the work in a branch
5. Submit a Pull Request

Only delegated contributors should work on a task unless collaboration is requested.

## Pull Request Guidelines

Please:
* Keep pull request in draft status until its ready for review.
* Reference the task ID in title.
* Include screenshots for UI changes.
* Respond to review feedback.

Merged work becomes part of the next sprint immediately.

## Questions & Coordination

Join my discord server [Nexus](https://discord.gg/AuVQcxSz) for questions and coordination.  

Contributors are encouraged to use Nexus for discussions. Inactive contributors may also opt to stay. Open tasks which are ready for bids will be posted there.  

A response time of 1 week is expected in Nexus and messages are purged when they are older than a week to keep the chat relevant.

Nexus members may also use 'lounge' channel for networking with other members.
